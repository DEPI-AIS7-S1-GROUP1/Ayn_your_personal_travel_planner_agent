# Personal Travel Planner

A travel planning website. A user signs up, fills in a short survey (hobbies,
personality, food preferences, last trip), and the system saves it as their
profile. The user then enters a destination, dates, budget and number of
travelers, and an AI agent builds a personalised day-by-day plan with a budget
split and mock flight/hotel options. The user reviews, edits, confirms and
rates the plan.

It is a normal interactive travel site — not a chatbot. The AI is the engine
behind the pages.
